# Web Stack: Astro + Hono + Fluent2

Published on: 2024-06-25

Finally, I will be using Astro, Hono and Fluent2 for developing my website.

Astro: Allows multiple JS frameworks to coexist + SSR + Cloudflare (CF) pages support

Hono: Can be used for backend. Allows fiddling with CF ecosystem

Fluent2: UI Library by Microsoft. Lock in with React, but can switch to WebStandards.

## What allowed me to jump ship

I bought the website viranchee.com since 5+ years, thinking to publish a blog on it along with serving some content, experimenting CF apis, etc.

Then, the pleathora of web frameworks, CF's ecosystem, opinions of people, and seeing practical works IRL, added to the confusion on what frameworks to use.

I got fond of Chakra-UI while chukling at Kitze's profanity during his live stream. Later, I tried RemixJS + ChakraUI but that didn't work well with CF Pages.

Specific JS Frameworks: Ecosystem lock-in
Non-JS ecosystem: Experimenting with JS in future becomes tedious

Github Issues as a blog / CRM: Good possibility, but after writing few I gave up.

My requirements were:

- ability to jump frameworks
- ability to experiment CF ecosystem
- JS UI libraries (ChakraUI / Fluent2)

Recently, while browsing through supported ecosystems on CF Pages, I found out Astro, Hono and Fluent2.
